# Private organiser guest experience preview

The QR Code page keeps its full-width real guest action, now labelled Open Live View App - What your guests see today. Two equally styled green actions directly below open the private invitation or seating timing mode. Exports are JPEG / PNG then Copy Link / Download PDF. Existing reset and public link/QR destination remain intact.

The new /organiser-preview/:eventId/:previewMode route uses the existing authenticated route gates. Its loader validates the session with getUser, checks can_access_event with the authenticated actor ID, and reads event, guest, table, module and saved floor-plan records through existing RLS. It creates no defaults and persists no customer snapshot. Session changes discard the view. No new database function, policy or public authorization override was introduced.

The real GuestLookup, verification gate, guest summary/details, table visualization and read-only plan components render the snapshot through a closed in-memory adapter. Before the seven-day window the SMS step is explicitly simulated with code 000000; it creates no verification token/session. Within the window the existing three-letter name selection and seat/table renderer are used. Mutation RPCs, unknown operations, Edge Functions and direct table writes fail closed. Submission/recording actions are unavailable, response controls are disabled, sharing the private route is disabled, and route analytics are skipped. Real guest routes never provide the preview context; date and SMS authorization remain server-controlled.

Existing and new saved events share this path, including events with absent optional module records. No billing behavior changes were made. Browser checks verified early simulation, seating search, table/seat display, tampered event denial and no messaging/guest mutations. Actual authenticated SQL role checks confirmed an unrelated account cannot authorize or read another event/guest records. The 47 public authorization regressions still pass. QR desktop/mobile checks confirm matching green styling and the exact action order.
