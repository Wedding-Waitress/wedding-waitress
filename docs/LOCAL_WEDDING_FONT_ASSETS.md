# Local Wedding Font Assets

The curated Wedding Waitress font collection is self-hosted. Runtime rendering,
preview, print, and PDF export do not request these families from Google Fonts.

All eight families are distributed under the SIL Open Font License 1.1. The
unmodified family-specific `OFL.txt` and Google Fonts `METADATA.pb` files are
stored beside the WOFF2 files in `public/fonts/<family>/`. OFL 1.1 permits
commercial use, embedding, bundling, and redistribution with software when the
copyright notice and licence accompany the font.

## Approved replacement mapping

| Unavailable family | Licensed local replacement | Intended role |
| --- | --- | --- |
| Beauty Mountains | Alex Brush | Wedding names and romantic script headings |
| Valentine Baby | Parisienne | Place-card and invitation accents |
| Amsterdam | Cormorant Garamond | Formal invitation typography |
| Back to Black Demo | Playfair Display | Refined romantic display headings |
| Flagfies | Cinzel | Formal seating-chart signage |
| Sphere Memory | Marcellus | Elegant names and short display text |
| ET Emilia Grace Demo | Lora | Readable invitation and signage support text |
| Grained | Bodoni Moda | Distinctive high-contrast display text |

Legacy saved settings are resolved to these real family names before display or
export. No replacement is registered under an unavailable font's name.

## Official sources

Vietnamese subsets returned by the official Google Fonts CSS API and hosted by
the official `fonts.gstatic.com` CDN. Copyright/licence metadata comes from the
official `google/fonts` repository.
